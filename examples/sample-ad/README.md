# Sample ad

`sample_9x16.mp4` is a real Hinglish ad for an Indian business ERP, made with the method Bizzbell packages:
a per-second screenplay, one character sheet, a keyframe per shot, image-to-video per shot, a TTS voice-over,
a voice-free music bed, every word as an overlay, and a -14 LUFS mix. The presenter is an AI-generated original
face, not a real person.
